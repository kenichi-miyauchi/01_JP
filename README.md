# 01 SDGs 複数課題への同時アプローチの提案
## 安全で衛生な水の確保とアグロフォレストリーによる 生計向上・児童労働抑止・CO2吸収の実現

SDGs の達成期限である2030年末が近づく中、依然として多くの課題が残されています。

水、栄養、貧困、児童労働、教育機会の喪失など、これらの課題はそれぞれ独立したものではなく、相互につながっています。
また、CO₂ 濃度が増すことによる地球温暖化に伴い、熱波、干ばつ、自然災害などの影響も深刻化しています。先進国が排出したCO₂ による気候変動が
途上国の子どもたちや地域社会を苦しめていることも見過ごせません。

約20年間、子ども支援を行う国連関係団体やNGOをサポートしてきました。
いろいろな支援の方法がある中、子ども支援NGOが行っているチャイルド・スポンサーシップが、比較的包括的なサポートだと感じていました。

地域開発によって生活を向上させつつ、児童労働をせずに学校に通うための取り組みです。
「貧困が児童労働を生み、教育機会を失い、次世代も貧困になる。」
この悪い流れを止める取り組みです。

一つひとつを個別に解決していくのではなく、更に複数の課題に同時にアプローチする方法はないかと考えました。

再生可能エネルギーから
→  海水淡水化・浄水(安全で衛生的な水の確保・水汲みの負担軽減)
→  節水技術 
→  アグロフォレストリー 
→  生計向上(地域開発) 
→  児童労働の抑止
→  教育機会の回復
→  森林育成
→  CO₂吸収

ありものを組み合わせた**「SDGs 複数課題への同時アプローチの提案」**です。

関係するSDGs
01 貧困をなくそう
02 飢餓をゼロに
04 質の高い教育をみんなに
05 ジェンダー平等を実現しよう
06 安全な水とトイレを世界中に
07 エネルギーをみんなに そしてクリーンに
08 児童労働の低減
13 気候変動に具体的な対策を
15 陸の豊かさも守ろう

私はこの分野の専門家ではなく、資金面や研究・実証の面でも、一人で実現できるものではありません。

部分的にでも活用できるアイデアや、研究・実証につながる可能性があれば、専門家の皆様に活用いただきたいと考えています。
