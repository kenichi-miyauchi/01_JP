# 01 SDGs 複数課題への同時アプローチの提案
## 安全で衛生な水の確保とアグロフォレストリーによる 生計向上・児童労働抑止・CO2吸収の実現

1 再生可能エネルギーを活用して、安全で衛生的な水を確保
　→ 子どもや女性の水汲みを無くします。

2 アグロフォレストリーにて農作物と森林を育成
　→ 生計向上により児童労働を低減して子どもが学校に通います。

3.育成された森林によりCO2吸収
　→ 多くの地域へ展開することで、CO2吸収に貢献します。
